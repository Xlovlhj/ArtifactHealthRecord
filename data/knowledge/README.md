# 循证资料库

`sources.json` 是可检索条目数组；`plan_sections.json` 是经原文核对的方案结构；`archive_sections.json` 是档案构成；`disease_catalog.json` 是首版六病害的术语映射和核验状态；`standards.json` 是标准版本登记表。

条目文本均为项目自撰摘要，`source_url` 链接到中国官方标准服务、文博机构或政府公开来源。摘要不代表原文授权开放，不包含原文图片。标准全文只临时下载用于核对，不随项目分发。

`verified=true` 仅表示已在记录的公开来源核对该摘要或元数据，不表示病例已由本项目专家复核，更不表示修复方法可直接用于另一件文物。`kind=case` 是公开案例摘要，必须结合 `record_completeness` 识别其不是完整临床式修复档案。未公布的配方、长期监测数据、专家签名和疗效不补造。

时间采用资料核查日 2026-10-28。资料原有发布日期另存于 `published_at`。网页日期或报道里的“今年”等不用于推定任务完成日期。
