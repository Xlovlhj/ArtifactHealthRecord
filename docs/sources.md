# 国内资料来源与使用记录

首批地域按用户要求选取甘肃／敦煌。核查日期为2026-10-28。资料库目前有37条可追溯摘要，其中4条是甘肃公开案例摘要，完整授权修复病例为0条；没有专家签名、真实试点合作或未公开病例数据。

数据文件为 `data/knowledge/sources.json`，每条含来源链接、出版机构、类型、标准和条款、版本、核验情况、权利说明、地域、材料、病害和公开结果。`kind=case` 表示公开事件摘要，不表示本项目拥有完整的检测、配方、施工与随访记录。

## 标准与工作原则

标准原文与元数据来源见 [标准核查记录](standards-verification.md)。30235、30236的内容仅写为项目简要摘要；标准正文不放入Git仓库。GB/T表示推荐性国家标准，不能只凭编号把项目内部规则称为法定强制要求。

[国家文物局2025年全流程管理通知](https://app.www.gov.cn/govdata/gov/202510/17/538614/article.html) 用作保护理念和流程提醒依据。软件草案不是工程审批文件。

[北京市文物局和平寺二次审核批复](https://wwj.beijing.gov.cn/bjww/362749/362751/cs88/326080920/index.html) 仅作为跨地区的方案证据完整性对照，标为 `北京（对照）` 和 `kind=principle`，不计入甘肃病例数。它表明实际审核会检查内部环境监测、材料分析、支撑体调查和现场试验之间的联系。

## 使用方式

检索时优先匹配具体对象材料、病害和地域，并显示来源性质及完整程度。自撰摘要可帮助定位证据，不代替阅读原文。若未找到支持某建议的条款或真实记录，输出证据不足。未经检测和试验，不生成材料品牌、浓度、施工配比或操作剂量。

`verified=true` 只表示该条摘要在给定来源已核对；它不等于“专家确诊”“临床验证”或“国标认证”。病害字典的条号与符号核查状态独立保存，不能由标准元数据的核验状态继承。

## 版权与后续采集

公开网页和可下载标准不自动授予影像再分发、训练或商业使用许可。本项目当前不收录这些来源的壁画图片、全文镜像或购买水印PDF。展示用教学图需独立标明为合成，不混入真实案例。

后续若获得馆方或项目单位授权，应补充授权对象、范围、期限、允许用途、脱敏规则、案例分组及撤回方式；再导入完整病例和影像。机构官网报道中的人名不被转成会诊专家账号，也不表示这些人员参与本项目。
