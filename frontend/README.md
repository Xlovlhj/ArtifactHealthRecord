# 文物病历前端

React 18 + TypeScript + Vite。构建结果由 FastAPI 同源提供，认证使用 HttpOnly Cookie。

在项目根目录执行 Python 入口，Python 和 Node 均由项目 conda 环境管理：

```console
python3 run.py build
python3 run.py serve
```

访问 `http://127.0.0.1:8765`。本地演示身份包括文保员、修复师、专家、管理者与管理员；非演示部署可以直接填写自定义用户名。开发服务器的 `/api` 会代理至本机 `8765`。

## 实现组织

| 文件 | 职责 |
| --- | --- |
| `src/App.tsx` | 登录、身份、导航、页面路由与全局消息 |
| `src/api.ts` | 请求、同源认证、任务轮询、带鉴权导出 |
| `src/overview.tsx` | 看板、建档检索、资料检索、审核队列、审计、能力状态 |
| `src/annotation.tsx` | 原图 SVG 坐标、多边形顶点编辑、两点尺度、模型候选与质量检查 |
| `src/assistance.tsx` | SAM 前景/背景点提示、完整候选掩膜预览、人工选类与采用 |
| `src/provenance.tsx` | 逐图来源、授权范围、独立来源复核与真实数据缺口台账 |
| `src/reference-images.tsx` | 真实开放馆藏图片、原始页面、逐视图预览与参考病历导入 |
| `src/workflow.tsx` | 基于当前病历版本的八步保护流程与待办入口 |
| `src/record.tsx` | 病历、资料、模拟滑块、影像对比与档案工作区 |
| `src/plans.tsx` | 13 章草案、逐章编辑与引用、不可变版本、规则和专家审核 |
| `src/ui.tsx` | 统一组件、请求状态和错误提示 |
| `src/styles.css` | 中文工作台与移动端布局，使用本机字体，无字体 CDN 依赖 |

多边形与标尺通过 SVG 屏幕坐标逆变换还原原图像素坐标；真实面积由服务端计算。拖动模型候选顶点或修改类型后，该区域自动转为人工来源，清除模型置信度及任务来源。未配置分割权重时仅显示质量分析与不可用说明，生成方案使用清晰标记的模板回退。

病历抽取默认只提交调查文字。勾选「同时读取当前影像／档案图」后，可以选择该病历内的一张影像；服务端缩放图片并检查视觉模型和外发授权。未配置时明确返回文字整理回退与不确定性说明。所有抽取结果仅为预览草稿，不会自动持久化。

SAM 辅助标注调用已有本地权重实现，通过异步任务返回候选；未配置权重时明确显示不可用。前景/背景点使用原图坐标，候选完整掩膜供人工核对。带孔洞或多连通区的候选不会静默转换成单一区域，必须人工逐区描绘；无孔洞单一区域可采用为未确认的人工标注，保留任务 ID、模型版本与内部评分依据。裂隙另行绘制真实中心线，保留用于面积统计的多边形。

「数据来源与缺口」分别显示已下载的真实开放馆藏参考照片和本机构的逐图来源台账。参考照片按真实馆藏对象分组，全部视图可预览与导入；导入后标记为公开参考病历，不生成病害或现场测量事实。来源编辑包括许可原文、授权用途、拍摄者、采集日期与壁画/遗址分组；来源复核由不同账号完成。合成图明确标记且不能计入真实评测，数量均来自后端实际数据。

## 浏览器验收

激活项目 conda 环境后执行：

```console
python3 frontend/tests/browser_smoke.py
```

测试自动在临时目录建立独立数据库，启动本地 `18765` 端口并使用 Playwright。优先复用系统 Chrome / Chromium，否则使用已安装的 Playwright Chromium。它不修改日常运行数据库，不调用外部模型。

覆盖真实页面中的建档、影像上传、来源补录、真实图库导入、标注面积、裂隙中心线、尺度、质量检查、病历修订、方案生成和版本比较、规则、提交、分身份审核、模拟与下载，以及移动端布局。SAM 未配置回退走真实异步 API；候选采用和复杂区域拒绝转换使用明确标记的浏览器响应夹具验证 UI，不作为模型效果证据。输出报告位于 `docs/frontend-validation.json`，教学和公开馆藏参考截图位于 `runtime/screenshots/`。
